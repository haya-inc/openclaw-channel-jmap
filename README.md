# @openclaw/jmap

JMAP email channel plugin for [OpenClaw](https://github.com/openclaw/openclaw). Enables email thread conversations over the [JMAP](https://jmap.io/) protocol.

## Features

- JMAP email send/receive
- Email thread session management
- Inbound message deduplication
- Mailbox monitoring

## Install

```bash
npm install @openclaw/jmap
```

## Configuration

Register as an OpenClaw channel plugin — see [OpenClaw channel docs](/channels/jmap) for setup details.

## Development

```bash
pnpm install
pnpm test
```
